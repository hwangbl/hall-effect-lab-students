学生入口（GitHub Pages 发布成功后）：<https://hwangbl.github.io/hall-effect-lab-students/>。

无需 GitHub 账号即可预习原理与副效应、查看真实仪器照片、操作三维连线和分步实验、观看学生演示，以及处理实验数据。课件和标准报告不随本仓库或网页提供，也没有下载入口；学生操作演示视频允许下载。

Pages 设置：Deploy from a branch → main → /(root)。所有资源使用相对路径，支持 GitHub Pages 仓库子路径。
